# 前端优化 + 功能增强 实施计划

> 日期：2026-07-31
> 目标：8 个改进点并行实施

## 一、问题清单与改进方案

### 1. 输入框样式修复（Quick Fix）
- **问题**：textarea 背景色 `bg-surface/50`（近乎黑色）与白色文字对比度低，用户看不清输入内容
- **方案**：改为深色但可见的背景 + 浅色文字 + 聚焦高亮，参考 Claude Code 输入框风格

### 2. 字体优化
- **问题**：当前使用 Inter 字体，不够"好看"
- **方案**：引入 JetBrains Mono（等宽字体用于代码/技术内容）+ 优化 Inter 字重配置 + 调整行高和字距

### 3. 流式输出 Auto-scroll 修复
- **问题**：流式生成时持续自动滚动到底部，用户无法查看历史消息
- **方案**：检测用户是否手动上滚，如果是则暂停自动滚动；用户滚动到底部后恢复

### 4. 历史对话管理
- **问题**：仅支持查看，不支持删除
- **方案**：
  - 每条历史记录添加删除按钮
  - 支持批量删除 / 清空全部
  - 按日期分组显示
  - 参考豆包：长按/右键菜单

### 5. 收藏功能（新功能）
- **方案**：
  - DB：新增 `Collection` 表（名称、用户ID）+ `CollectionItem` 表（关联法规/条文）
  - API：CRUD 接口
  - UI：法规详情页添加"收藏"按钮 + 收藏夹管理页面

### 6. 向量化 MVP
- **方案**：仅向量化 5 部核心法律（民法典、劳动合同法、劳动法、刑法、民事诉讼法），减少 token 消耗

### 7. 管理员账号
- **方案**：提供默认 admin/admin123 账号，写入 seed 脚本

### 8. 前端全面优化
- **方案**：基于纯黑多巴胺主题继续打磨，参考 Claude Code 终端审美

## 二、并行执行策略

| 工作流 | 任务 | 依赖 |
|--------|------|:----:|
| 快速修复 | 输入框 + 字体 + Auto-scroll | 无 |
| 功能开发 | 历史删除 + 收藏系统 | 需 DB migrate |
| 数据 | 向量化 + 管理员账号 | 无 |
| 前端 | 视觉打磨 | 无 |
